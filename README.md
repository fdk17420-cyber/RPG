# 🐉 ドラゴンクエスト風RPG

ドラゴンクエストにインスパイアされたシンプルなPython RPGゲーム。ターンベースの戦闘システムで敵と戦い、レベルアップを目指しましょう！

## 🎮 ゲームの特徴

- **ターンベース戦闘**: 素早さで行動順序が決定される戦略的な戦闘システム
- **スキル・魔法システム**: 複数のスキルや魔法を習得して、戦闘を有利に進める
- **レベルアップシステム**: 経験値を獲得してレベルアップし、ステータスが上昇
- **複数の敵キャラクター**: スライム、ゴブリン、スケルトンなど様々な敵と戦闘
- **ゴルド報酬**: 敵を倒してゴルドを獲得

## 📋 必要な環境

- Python 3.7 以上

## 🚀 遊び方

### 1. ゲーム開始

```bash
python main.py
```

### 2. 勇者の名前を入力

ゲーム開始時に勇者の名前を入力します。

### 3. メインメニュー

```
【メインメニュー】
1. 敵と戦闘
2. ステータス確認
3. スキル一覧
4. ゲーム終了
```

### 4. 戦闘

敵が現れたら、以下のアクションから選択して戦闘を進めます：

```
【アクション選択】
1. 通常攻撃 - 敵に基本ダメージを与える
2. スキル/魔法 - MP消費してスキルを使用
3. ステータス確認 - 自分のステータスを確認
```

## 📊 キャラクターステータス

| 項目 | 説明 |
|------|------|
| HP | 体力。0になるとゲームオーバー |
| MP | 魔力。スキル使用時に消費 |
| 攻撃力 | 与えるダメージ量に影響 |
| 防御力 | 受けるダメージを軽減 |
| 素早さ | ターン順序に影響 |
| レベル | 敵を倒して経験値を獲得するとアップ |
| ゴルド | 敵を倒すと獲得できる通貨 |

## ⚔️ スキル・魔法一覧

### 勇者のスキル

| スキル名 | MP消費 | 効果 | 説明 |
|---------|--------|------|------|
| 斬撃 | 0 | 通常攻撃 | 基本的な斬撃。MP消費なし |
| パワースラッシュ | 8 | 高威力攻撃 | より強力な斬撃 |
| ホイミ | 5 | 回復 | 自分のHPを30回復 |
| ベホイミ | 15 | 大回復 | 自分のHPを80回復 |
| イオ | 10 | 氷属性魔法 | 敵に氷の魔法で攻撃 |
| ライデイン | 12 | 電撃魔法 | 敵に電撃で攻撃 |

### 敵スキル

敵も様々なスキルを使用して攻撃してきます。

|------|----|----|----|----|-----|
| スライム | 20 | 8 | 2 | 50 | 30 |
| ゴブリン | 35 | 12 | 4 | 100 | 60 |
| スケルトン | 40 | 15 | 6 | 150 | 100 |

## 🎯 ゲーム目標

1. **敵を倒す** - 毎ターン敵と戦闘し、敵を倒す
2. **レベルアップする** - 経験値を獲得してレベルアップ
3. **ステータスを上げる** - レベルアップによってHPや攻撃力が上昇
4. **ゴルドを集める** - 敵を倒してゴルドを獲得
5. **できるだけ長く生き残る** - ゲームオーバーになるまで継続

## 💡 戦闘のコツ

- **ダメージ計算**: ダメージ = 攻撃力 + スキル威力 ± ランダム値
- **防御力の効果**: 敵のダメージを防御力の半分だけ軽減
- **MP管理**: MPが尽きるとスキルが使えなくなるため、回復スキルのバランスが重要
- **敵の素早さ**: 敵より素早さが高いと、先制攻撃できる確率が上がる

## 🔧 コードの構成

### character.py
- **Character** - キャラクター基本クラス
- **Player** - プレイヤー（勇者）クラス
- **Enemy** - 敵キャラクタークラス

### skills.py
- **Skill** - スキル基本クラス
- 各種スキルクラス（Slash, PowerSlash, Heal など）
- **SkillList** - スキル管理クラス

### battle.py
- **Battle** - 戦闘システムクラス
- **BattleFactory** - 敵生成ファクトリー

### main.py
- **Game** - ゲーム全体を管理するクラス
- メインメニュー
- ゲームループ
