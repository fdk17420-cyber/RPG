# 🐉 ドラゴンクエスト風RPG - 完全版

ドラゴンクエストにインスパイアされたPython RPGゲーム。ターンベースの戦闘システム、ダンジョン探索、NPC との会話、装備品システムなど、豊富な機能を備えた本格的なRPGです。

## ✨ 新機能（完全版）

### 🎮 拡張されたゲームシステム

- ✅ **セーブ・ロード機能** - 3つのセーブスロットで進行状況を保存
- ✅ **インベントリシステム** - アイテムと装備品を管理
- ✅ **アイテム購入システム** - ショップでアイテムを買売
- ✅ **装備品システム** - 武器・防具・アクセサリーでステータスアップ
- ✅ **ボスキャラクター** - ゴブリンキング、スケルトンキング、ダークロード、ドラゴン
- ✅ **ダンジョン探索** - 5つのダンジョンで10階層の冒険
- ✅ **NPC との会話** - 商人やクエスト依頼者と対話
- ✅ **クエストシステム** - 敵を倒してクエストを完了し報酬獲得
- ✅ **大幅に拡張された敵** - 20種類以上の敵キャラクター

## 📋 必要な環境

- 標準ライブラリのみ（外部ライブラリ不要）

## 🎯 ゲーム目標

1. **敵を倒す** - 毎ターン敵と戦闘
2. **レベルアップ** - 経験値を獲得してLvアップ
3. **装備品を集める** - ショップでアイテムを購入
4. **ダンジョンをクリア** - 5つのダンジョン全制覇
5. **ドラゴンを倒す** - ゲーム最終目標

## 💡 ゲームのコツ

### 戦闘のコツ
- ダメージ = 攻撃力 + スキル威力 ± ランダム値
- 防御力は敵のダメージを軽減（防御力の半分）
- MP管理が重要（スキル使用時に消費）
- 素早さが高いと先制攻撃できやすい

### ダンジョン探索のコツ
- 浅い階層から挑戦して経験値を稼ぐ
- 装備品を整える前に深い階層には挑戦しない
- 脱出確率は階層が浅いほど高い
- ボス敵との戦闘は最高の装備で臨む

### アイテム購入のコツ
- ゴルドは回復アイテムより装備品に投資
- 装備品でステータスアップすれば、より強い敵に対応可能
- 高級装備は高価だが効果は絶大

## 📈 ステータス説明

| 項目 | 説明 |
|------|------|
| HP | 体力。0になるとゲームオーバー |
| MP | 魔力。スキル使用時に消費 |
| 攻撃力 | 与えるダメージに影響（装備品でアップ可能） |
| 防御力 | 受けるダメージを軽減（装備品でアップ可能） |
| 素早さ | ターン順序に影響 |
| レベル | 敵を倒して経験値を獲得するとアップ |
| ゴルド | 敵を倒すと獲得。ショップで使用 |
